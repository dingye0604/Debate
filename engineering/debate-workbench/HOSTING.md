# 远端运行说明

这是待部署源码说明，不代表已经公开发布。实际部署、域名绑定与服务器设置需由维护者决定。

## 运行条件

- 一个 Python 3.12 单进程运行环境及可持久保存 data/ 的磁盘。
- 一个 HTTPS 反向代理或提供同等能力的托管入口。
- 外网能够访问使用者填写的模型服务与搜索服务。
- 持久挂载 data/，停止服务后进行备份；不要把 data/ 或备份目录作为静态资源公开。

纯静态托管不能运行当前的 Python 检索、文件存储与后台任务。如果只在笔记本上使用，继续运行 run.py 即可，不需要配置本节内容。

## 启动示例

假设反向代理与应用运行在同一台主机，HTTPS 入口是你自己的域名：

```text
python run.py --no-browser --remote-origin https://debate.example.com --host 127.0.0.1 --port 8766 --trusted-proxy 127.0.0.1
```

这是示例域名，运行前替换为自己的 HTTPS 域名。反向代理将请求转给 http://127.0.0.1:8766，并设置原始 Host 与 X-Forwarded-Proto: https。仅信任指定代理 IP；不要使用通配符。代理在其他容器中时，按实际网络设置 --host 与 --trusted-proxy，并在平台网络层只允许该代理访问应用端口。

应用只接受配置的 Host 与 Origin，并要求远端请求经可信代理标记为 HTTPS。勿直接通过 uvicorn app:app 启动分享版：该默认实例是本机模式。勿启用多个 worker、自动扩缩到多个副本或调试模式。

## 密钥与档案边界

- 不填写维护者统一密钥；所有使用者在网页中自行设置 API。
- 密钥只存内存，有效期两小时；进程重启后重新填写。
- Cookie 使用 Secure、HttpOnly、SameSite=Lax 和 __Host- 前缀。
- 反向代理和托管平台不得记录请求体、Cookie 或 Authorization；不要启用会采集表单内容的分析脚本。
- 此版本没有邮箱账号、跨设备找回或后台用户管理。浏览器 Cookie 是访问档案的凭证。
- 服务器维护者仍可读取磁盘上的档案。本应用提供访客之间的访问隔离，不是端到端加密存储。

## 已有边界与运行限制

应用校验 CSRF、输入大小、请求频率、每访客一个任务与全局四个运行/连接请求；每访客最多 50 份档案，每份最多 600 条历史事件、240 个来源。模型响应上限 2 MB，单次模型网络请求总超时 150 秒；正文获取和检索分别有数量、大小及时间限制。

模型目标必须为 HTTPS 公网域名及 443 端口。DNS 解析结果校验后固定实际连接地址，并保留原域名的 TLS 校验；不跟随模型接口重定向。正文跳转每次重新校验。仅本机模式兼容 198.18.0.0/15 的 Fake-IP 代理，远端模式禁止。

这些限制适合小规模分享，不替代托管平台的防滥用与磁盘配额。匿名访客可以新建空间，因此对广泛公开的高流量站点，还应在托管入口设置总请求与存储预算，并按实际需求增加账户体系；这不在本轮实现范围内。

## 发布前检查

1. 解压 package_source.py 生成的源码包，在独立环境运行测试。
2. 配置 HTTPS 和单进程后台，确认远端页面显示 SHARED，且未经 HTTPS 的请求被拒绝。
3. 两个独立浏览器填写各自模型，检查档案不可互访、下载正常。
4. 重新启动后，确认档案仍可访问、模型显示尚未连接。
5. 确认平台访问日志不记录请求体、Cookie 或密钥，并设置磁盘预算。

本轮仅完成本机运行、模拟远端边界和浏览器验收；尚未在实际托管平台验证证书、代理、磁盘挂载或公网负载。
