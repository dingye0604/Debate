# 辩序 · AI 备赛工作台

输入辩题与持方，与 AI 教练按五阶段流程完成备赛，下载 Markdown 和 ZIP 档案。支持访客自行配置 OpenAI / Anthropic 兼容 API、访客档案隔离，以及浅色/深色玻璃风格界面。

应用源码位于 [engineering/debate-workbench](engineering/debate-workbench)。

- [本机安装与使用](engineering/debate-workbench/README.md)
- [远端托管说明](engineering/debate-workbench/HOSTING.md)
- [验证记录](engineering/debate-workbench/VERIFICATION.md)

已有项目环境可双击「启动备赛.cmd」。首次安装请按应用 README 创建独立环境。

仓库不包含个人模型配置、API Key、备赛数据、运行环境或缓存。公开网页需要运行 Python 后端；上传到 GitHub 本身不会自动部署网站。
